# 4 Radio Button

参考视频四款 A/B 单选动效的逐帧矢量复刻：拉伸横线、收缩边框、跳跃方块、下沉凸起。

直接用浏览器打开 `index.html`，无需安装依赖。

## 动画与交互

- 以 60 fps 采样原视频的首个完整往返周期，使用 144 帧矢量轮廓重建 2.4 秒循环，每 1.2 秒换向。
- 布局、文字轮廓、签名、小狗图案、颜色，以及每帧的旋转、位移、形变和文字渐变均取自参考视频。
- 页面默认同步演示；点击任一选项后，各组可独立操作，其余组完成当前动画后停下。刷新页面重新演示。
- 原生 radio 支持 Tab 和方向键，并遵循系统的减少动态效果设置。
- 添加 `?frame=0` 到 `?frame=143` 可暂停在指定参考帧，便于逐帧核对。

## 文件

- `index.html`：页面结构及原生单选输入。
- `style.css`：正方形画布缩放、交互区域与键盘焦点。
- `script.js`：60 fps 时间轴、逐帧矢量渲染及独立交互。
- `assets/chrome.svg`：静态区域的矢量轮廓。
- `assets/motion.js`：四组按钮的逐帧轮廓和灰度颜色；重复路径复用索引。

轮廓在原片 1790×1790 分辨率下提取，使用 SVG 路径绘制。视频压缩、轮廓简化与浏览器抗锯齿仍会产生少量边缘像素差异。
